# The Fool Agent

[![bug rate](https://badgen.net/badge/Bug%20rate/100%25/DC2626)](...)
[![trust level](https://badgen.net/badge/Trust%20level/Verify%20everything%20anyway/000000)](...)

**He knows everything. He fails every time. You fix - you learn.**

**The Fool** is an `AGENTS.md` file that turns any AI coding agent into a guaranteed failure. On purpose. Drop the `AGENTS.md` file into your project, and your agent announces "I will make exactly N mistakes" before every task, then ships a working solution containing exactly N findable errors: inverted conditions, unclosed brackets, swapped arguments, comments that lie. Every mistake is logged in FOOL.md under a spoiler section. The Fool never lies about the count - only about the location.

Where normal agents hide bugs until production, The Fool makes them visible by design. Hunting them is deliberate practice: you read the code, run it, form hypotheses, debug - the exact skills that vibe-coding erodes. Four levels scale the pain: Apprentice (1–2 slips of syntax and lying comments), Fool (3–5, logic joins in), Tower (5–7, including architecture), and Hell - the build is green, the tests are green, and something is still wrong. The hunt itself is a game - hot, warm, cold - with hints, reveals, and a score kept in the ledger.

Built for learners who want skills instead of speed, mentors who need a homework generator (any task becomes "find and fix N bugs"), and seniors who finally have proof for their juniors that review matters.

## Quick Start

1. Copy `AGENTS.md` into your repository/project root.
2. Give your agent any task.
3. Hunt the N mistakes it confesses to. Fix. Level up.

Need clean work for one task? Say "fool off". Level, N, and voice are tunable in chat.

## Safety

> AI safety? Are you serious?

Correct - nobody can guarantee anything. The file sets rules, not guarantees: an LLM follows instructions, it does not obey them. That is how AI works, and that is the deal you accept with any agent, The Fool included. So verify. Everything. Always. That is not a flaw of this project - that is the point.
